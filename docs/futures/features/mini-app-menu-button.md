# Mini App в кнопке меню — Roadmap

Приоритет: 🟡 средний.

Связано с: вкладка **«Бот»** → настройки карточки токена; клоны / пул выдачи ботов.

---

## Идея одной фразой

В настройках бота (вкладка **Бот**) включить Mini App в кнопке меню (вместо «Menu») и автоматически выставлять её через Bot API `setChatMenuButton` при сохранении / старте токена — в том числе у клонов.

---

## Контекст

Сейчас у каждого бота кнопка меню по умолчанию открывает список команд. Mini App в этой кнопке можно поставить:

- вручную в @BotFather (`/setmenubutton`);
- или через Bot API: `setChatMenuButton` / `getChatMenuButton`.

При клонировании токена настройка **не наследуется** — её нужно применять к каждому боту отдельно. Автоматизация на старте/сохранении как раз это закрывает.

**Не путать** с Main Mini App (кнопка Launch на профиле бота) — та настраивается только через BotFather (`/newapp` и т.п.), через Bot API недоступна. Домен (`/setdomain`) тоже только через BotFather, на каждый бот.

---

## UI (вкладка «Бот»)

В сетке настроек карточки токена (`BotSettingsGrid`):

- тумблер «Mini App в меню»;
- поле текста кнопки (например «Открыть»);
- поле HTTPS URL Mini App;
- подсказка: это только меню-кнопка, не Launch на профиле; домен нужно один раз прописать в BotFather (`/setdomain`).

Опционально позже: хранить URL на уровне **проекта** и применять ко всем токенам проекта (удобно для клонов с одним приложением).

---

## Backend / runtime

1. Поля в настройках токена (или проекта): `menuButtonEnabled`, `menuButtonText`, `menuButtonUrl`.
2. При старте бота / сохранении настроек — вызов `setChatMenuButton` с `type: "web_app"` (без `chat_id` = дефолт для всех чатов).
3. При выключении тумблера — сброс на `type: "commands"` или `default`.
4. Ошибки Telegram (невалидный URL, домен не в whitelist) — показать в UI / логах, бот не ронять.

---

## Критерии готовности

- [ ] UI на вкладке «Бот»: тумблер + текст + URL
- [ ] Сохранение в БД (токен и/или проект)
- [ ] `setChatMenuButton` при старте и при сохранении
- [ ] Сброс кнопки при выключении
- [ ] Подсказка про `/setdomain` и отличие от Main Mini App
- [ ] (опционально) одна настройка проекта → все токены

---

## Вне скоупа

- Main Mini App / Launch на профиле
- `/setdomain`, `/newapp` через API (невозможно)
- Attachment menu Mini App
