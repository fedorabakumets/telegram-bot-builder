# health

Эндпоинтов: **1**

### `GET` /api/health

Healthcheck компонентов

**Авторизация:** Публичный

Публичный эндпоинт liveness/readiness. Используется UI (`ServerStatus`), Railway healthcheck и балансировщиками. Заменяет устаревший `GET /api`. Для проверки без JSON допустен `HEAD /api/health` (ответ 204).

#### Ответы

| Код | Описание |
|-----|----------|
| 200 | Статус компонентов |
