### `GET` /api/projects/{id}/tables

Список таблиц контента проекта

**Авторизация:** Cookie (`connect.sid`)

Возвращает пользовательские таблицы bot_tables для редактора Database. Требует доступ к проекту (requireProjectAccess).

#### Параметры

| Имя | In | Обязательный | Описание | Пример |
|-----|-----|--------------|----------|--------|
| `id` | path | да | — | `"42"` |

#### Ответы

| Код | Описание |
|-----|----------|
| 200 | Массив таблиц |
| 400 | Некорректный ID проекта |
