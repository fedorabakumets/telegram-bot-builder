# agent-connections

Эндпоинтов: **2**

### `GET` /api/agent-connections

Подключения владельца браузерной сессии

**Авторизация:** Cookie (`connect.sid`)

PAT не заменяет браузерную сессию.

#### Ответы

| Код | Описание |
|-----|----------|
| 200 | Подключения без секретов |
| 401 | SESSION_REQUIRED |
| 503 | AUTO_AUTH_UNAVAILABLE: ключ, Redis или БД недоступны |

### `PATCH` /api/agent-connections/{id}

Отключить или явно восстановить своё подключение

**Авторизация:** Cookie (`connect.sid`)

Только браузерная сессия владельца и совпадающий Origin. Отключение отзывает все PAT. Включение не восстанавливает старые PAT.

#### Параметры

| Имя | In | Обязательный | Описание | Пример |
|-----|-----|--------------|----------|--------|
| `id` | path | да | — | — |
| `Origin` | header | да | — | — |

#### Ответы

| Код | Описание |
|-----|----------|
| 200 | Состояние сохранено |
| 400 | INVALID_REQUEST |
| 401 | SESSION_REQUIRED |
| 403 | ORIGIN_MISMATCH |
| 404 | NOT_FOUND: чужое или отсутствующее подключение |
| 503 | AUTO_AUTH_UNAVAILABLE: ключ, Redis или БД недоступны |
