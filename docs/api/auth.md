### `POST` /api/auth/telegram

Вход / смена аккаунта через Telegram Login Widget

**Авторизация:** Публичный

Публичный. Только реальный login (не restore после reload). Создаёт/обновляет пользователя и устанавливает session cookie. Повторный вызов с другим id = смена аккаунта: сервер регенерирует session, в ответе switched=true. В production без SKIP_AUTH поле id_token обязательно.

**Тело запроса:** `TelegramAuthRequest`

#### Ответы

| Код | Описание |
|-----|----------|
| 200 | Авторизация успешна, cookie установлена |
| 400 | Не передан id |
| 401 | Требуется или невалиден id_token / proof |
| 429 | Rate limit auth |
