# Диалоги

Эндпоинтов: **3**

### `GET` /api/projects/{projectId}/dialogs

Список диалогов выбранного бота

**Авторизация:** Cookie (`connect.sid`) или Bearer PAT

Читает сохранённые диалоги без запросов Telegram. Личные карточки требуют личных сообщений выбранного бота; групповые сообщения не меняют их превью и порядок. Статус доступа — последняя проверка, счётчик — сохранённые сообщения. Курсор привязан к проекту, токену, виду и поиску; при новых сообщениях снимок выдачи не гарантируется.

#### Параметры

| Имя | In | Обязательный | Описание | Пример |
|-----|-----|--------------|----------|--------|
| `projectId` | path | да | — | — |
| `tokenId` | query | да | — | — |
| `kind` | query | нет | — | — |
| `search` | query | нет | — | — |
| `limit` | query | нет | — | — |
| `cursor` | query | нет | — | — |

#### Ответы

| Код | Описание |
|-----|----------|
| 200 | Страница диалогов и сохранённые проверки доступа |
| 400 | Некорректные параметры или курсор |
| 401 | Требуется авторизация |
| 403 | Нет доступа к проекту |
| 404 | Бот не принадлежит проекту |
| 500 | Не удалось прочитать диалоги |

### `GET` /api/projects/{projectId}/dialogs/{chatId}/messages

Страница сохранённой истории чата

**Авторизация:** Cookie (`connect.sid`) или Bearer PAT

Только чтение БД. Первая страница содержит последние сообщения, внутри страницы порядок хронологический. next_cursor ведёт к более старым сообщениям. История ограничена сроком хранения; курсор привязан к проекту, боту, чату, типу и включению группового контекста. Данные Telegram не запрашиваются.

#### Параметры

| Имя | In | Обязательный | Описание | Пример |
|-----|-----|--------------|----------|--------|
| `projectId` | path | да | — | — |
| `chatId` | path | да | — | — |
| `tokenId` | query | да | — | — |
| `chatType` | query | да | — | — |
| `limit` | query | нет | — | — |
| `cursor` | query | нет | — | — |
| `includeGroupContext` | query | нет | — | — |

#### Ответы

| Код | Описание |
|-----|----------|
| 200 | Страница истории с исходными чатами и безопасными метаданными вложений. Пустая страница допустима. |
| 400 | Некорректные параметры, курсор или групповой контекст для неличного чата |
| 401 | Требуется авторизация |
| 403 | Нет доступа к проекту |
| 404 | Бот не принадлежит проекту |
| 500 | Не удалось прочитать историю |

### `GET` /api/projects/{projectId}/dialogs/messages/search

Поиск по сохранённым сообщениям бота

**Авторизация:** Cookie (`connect.sid`) или Bearer PAT

Буквальная подстрока без регистра, включая %, _ и обратную косую черту. Без chatId поиск по всем чатам; chatType допустим как самостоятельный фильтр. Для chatId требуется chatType. Порядок от новых к старым; курсор привязан к проекту, токену, запросу и фильтрам. Только сохранённый текст, без Telegram.

#### Параметры

| Имя | In | Обязательный | Описание | Пример |
|-----|-----|--------------|----------|--------|
| `projectId` | path | да | — | — |
| `tokenId` | query | да | — | — |
| `query` | query | да | — | — |
| `chatId` | query | нет | — | — |
| `chatType` | query | нет | — | — |
| `limit` | query | нет | — | — |
| `cursor` | query | нет | — | — |

#### Ответы

| Код | Описание |
|-----|----------|
| 200 | Совпадения от новых к старым с полным текстом и безопасными метаданными. |
| 400 | Некорректные параметры или курсор |
| 401 | Требуется авторизация |
| 403 | Нет доступа к проекту |
| 404 | Бот не принадлежит проекту |
| 500 | Не удалось выполнить поиск |
