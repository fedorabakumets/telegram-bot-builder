# Диалоги

Эндпоинтов: **1**

### `GET` /api/projects/{projectId}/dialogs

Список диалогов выбранного бота

**Авторизация:** Cookie (`connect.sid`) или Bearer PAT

Читает сохранённые диалоги без запросов Telegram. Статус доступа — последняя проверка, счётчик — сохранённые сообщения. Курсор привязан к проекту, токену, виду и поиску; при новых сообщениях снимок выдачи не гарантируется.

#### Параметры

| Имя | In | Обязательный | Описание | Пример |
|-----|-----|--------------|----------|--------|
| `projectId` | path | да | — | — |
| `tokenId` | query | да | — | — |
| `kind` | query | нет | — | — |
| `search` | query | нет | — | — |
| `limit` | query | нет | — | — |
| `cursor` | query | нет | — | — |

#### Ответы

| Код | Описание |
|-----|----------|
| 200 | Страница диалогов и сохранённые проверки доступа |
| 400 | Некорректные параметры или курсор |
| 401 | Требуется авторизация |
| 403 | Нет доступа к проекту |
| 404 | Бот не принадлежит проекту |
| 500 | Не удалось прочитать диалоги |
