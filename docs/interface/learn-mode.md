# Режим обучения

Режим обучения — пошаговый гид по экрану: проводник печатает короткие пояснения, а интерфейс постепенно «открывает» элементы (вкладки, фильтры, карточки), чтобы новичок не увидел всё сразу.

Сейчас полноценный пошаговый режим есть на странице **«Сценарии ботов»**. Рядом по духу — короткий диалог на экране **«нет проектов»** (не шаги, а приветствие перед кнопками).

## Зачем он нужен

- Объяснить раздел словами, а не отдельной длинной справкой.
- Показать, *куда смотреть*: элемент появляется вместе с текстом про него.
- Не мешать опытным: обучение можно пропустить и пройти снова с кнопки.

## Как это выглядит на «Сценариях»

1. Если у вас **нет проектов**, при входе на страницу обучение может стартовать само.
2. Сверху — панель **«Режим обучения»**: шаг N из M, прогресс-полоска, текст проводника.
3. Кнопки: **Назад**, **Далее** (активна, когда текст допечатался), **Пропустить**.
4. На последнем шаге — **«Я понял»** (закрывает обучение).
5. В шапке всегда есть кнопка **«Обучение»** — запустить заново с первого шага.

Пока идёт обучение, вкладки, поиск/фильтры и сетка карточек появляются по сценарию шагов (сначала пусто → вкладки по одной → фильтры → выбор шаблона).

### Что рассказывают шаги (кратко)

| Шаг | О чём |
|-----|--------|
| Старт | Зачем страница «Сценарии» и что такое шаблон |
| Все | Полный каталог шаблонов |
| Рекомендуемые | Подборка для первого запуска |
| Популярные | То, что чаще берут другие |
| Мои | Личная полка сохранённых шаблонов |
| Поиск | Строка поиска, категория, сортировка |
| Выбор | Нажать «Использовать» на карточке |

Точные тексты живут в коде: `client/components/editor/scenariy/learn/scenariy-learn-steps.ts`.

## Пропуск и повтор

- **Пропустить** / **Я понял** — обучение скрывается; автозапуск больше не мешает.
- Пометка хранится в браузере (`localStorage`), не на сервере.
- **Обучение** в шапке снимает пометку и снова ведёт с шага 1.

## Экран «нет проектов»

Это не тот же пошаговый режим, а короткий печатный диалог («проектов ещё нет → с нуля / шаблон / JSON»), после которого появляются кнопки действий. Повторный визит в тот же браузер показывает текст сразу, без анимации набора.
