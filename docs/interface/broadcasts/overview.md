# 📢 Вкладка «Рассылки»

«Рассылки» — это место, где можно массово отправить одно сообщение сразу многим пользователям бота и потом посмотреть, как прошла отправка. Здесь собран список всех ваших рассылок со сводной статистикой и статусами, а по каждой рассылке можно открыть подробности: кому отправляли, сколько сообщений дошло и где возникли ошибки. Эта страница — обзор вкладки и точка входа к руководству по созданию рассылки.

## Где создавать рассылки

Основной способ — **вкладка «Диалоги»**: там в списке слева есть строка «Рассылка», которая открывает ленту всех рассылок проекта, а из неё запускается мастер новой рассылки. Именно в этой ленте доступны все действия над уже отправленной рассылкой: поправить текст, остановить или удалить сообщения у получателей.

Вкладка «Рассылки» осталась как история отправок и сводная статистика. В её верхней части показан баннер «Устаревшая вкладка»: он сообщает, что рассылка переехала в панель диалога, а функциональность отсюда со временем уйдёт туда же. Баннер не мешает работать — список рассылок виден, запущенные рассылки отслеживаются. Но начинать лучше из «Диалогов».

## Одна рассылка или большая рассылка

Рассылка бывает двух видов:

- **От одного бота** — обычная рассылка: одно сообщение, один бот, свои получатели.
- **Большая рассылка** — одно сообщение уходит параллельно от нескольких ботов проекта. В мастере для этого достаточно оставить отмеченными нужных ботов (по умолчанию отмечены все). В ленте рассылок на вкладке «Диалоги» она видна одной записью: общие счётчики по всем ботам и раскрываемый список ботов с отдельными статусами.

Правка текста, остановка и удаление у большой рассылки применяются сразу ко всем её ботам, но отдельного бота можно остановить или удалить из неё поштучно.

## Список рассылок

Основную часть экрана занимает список всех рассылок проекта. Над ним выводится сводная статистика по трём показателям сразу по всем рассылкам:

| Показатель | Что означает |
|------------|--------------|
| Всего отправлено | Сколько сообщений всего ушло во всех рассылках |
| Доставлено | Сколько из них успешно дошло до получателей |
| Ошибок | Сколько сообщений отправить не удалось |

У каждой рассылки в списке есть статус, который показывает, на каком она этапе: ожидает запуска, идёт прямо сейчас, завершена, остановлена вручную или закончилась с ошибкой. Пока рассылка идёт, рядом виден прогресс отправки, чтобы было понятно, насколько она продвинулась. Если рассылок накопилось много, список разбивается на страницы — листайте, чтобы добраться до более старых записей.

Статусы и прогресс обновляются вживую, без перезагрузки страницы.

Важная особенность: на этой вкладке большая рассылка показана **отдельной строкой на каждого бота** — так удобно смотреть отправку конкретного бота, но общей картины по всей рассылке здесь нет. Чтобы увидеть её одной записью с общим статусом, откройте ленту рассылок на вкладке «Диалоги». Там у большой рассылки статус собирается из статусов всех её ботов:

| Статус | Когда показывается |
|--------|--------------------|
| В очереди | Отправка ещё не началась |
| Отправка… | Хотя бы один бот ещё отправляет |
| Завершена | Все боты отправили без сбоев |
| Остановлена | Отправку прервали (полностью или у части ботов) |
| Частично | У части ботов рассылка завершилась ошибкой, у остальных прошла |
| Ошибка | Отправка не удалась у всех ботов |

## Детали выбранной рассылки

Выберите любую рассылку из списка, чтобы открыть её подробности. В деталях собраны итоги именно этой рассылки:

- **Аудитория** — сколько получателей было выбрано.
- **Доставлено** — сколько сообщений дошло.
- **Ошибок** — сколько сообщений не удалось отправить.
- **Успех** — доля успешных доставок в процентах.

Ниже приводится разбор ошибок доставки: по каким получателям сообщение не прошло и почему. Это помогает понять, что пошло не так, — например, пользователь заблокировал бота. Если рассылка ещё идёт, эти цифры обновляются в реальном времени.

Поскольку большая рассылка представлена здесь строкой на каждого бота, в деталях вы видите итоги одного бота. Общие цифры по всем ботам и разбивку по каждому из них показывает лента рассылок на вкладке «Диалоги»: там достаточно раскрыть список ботов у нужной записи.
