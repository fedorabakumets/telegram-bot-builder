# 🖥️ Вкладка «Терминал»

«Терминал» показывает живой вывод запущенного бота: строки появляются в реальном времени, пока бот работает. Это место, где видно, что именно делает бот прямо сейчас, какие сообщения он обрабатывает и где возникают ошибки. Терминал помогает быстро понять, всё ли в порядке, и найти причину сбоя, если что-то пошло не так.

## Живой вывод и ошибки

Пока бот запущен, его вывод поступает в терминал построчно, без задержки. Все строки делятся на два вида:

- **Обычный вывод** — рабочие сообщения о действиях бота.
- **Ошибки** — строки с проблемами, которые подсвечиваются отдельно, чтобы их было легко заметить.

Такое разделение позволяет сразу отличить штатную работу бота от сбоев.

## Фильтр и поиск

Над таблицей логов — одна строка в духе Railway:

- поле **«Фильтр и поиск логов»** с навигацией ↑/↓ по совпадениям;
- чипы **Все / Вывод / Ошибки** (счётчик ошибок на «Ошибки»);
- меню **Опции** — масштаб, очистка, копирование и скачивание (текст / JSON / CSV).

Enter — следующее совпадение, Shift+Enter — предыдущее.

Вывод выглядит как таблица: колонки **Время**, **Уровень** (info/err) и **Данные**. Над панелью — контекст: «Живые логи / token #…» или дата запуска `/ #launchId`.

Гидрация и API логов берут последний launch из истории запусков; для running подмешиваются live-строки без `launch_id`. Изоляция `token_id` в worker-pool: [[features/bot-worker-pool-isolation]].

Терминал оформлен в теме приложения: обычный фон и текст, как у остальной панели, одинаковые отступы у контекста, тулбара и строк. Цветом остаются только ошибки и ANSI-раскраска, которую бот выводит сам.

## Периоды логов

Рядом с поиском доступен выбор **Текущий запуск / Последние 15 минут / Последний час / Последние 24 часа / Сегодня / Вчера / Свой период**.

**Текущий запуск** выбран по умолчанию и обновляется в реальном времени. Остальные периоды загружают сохранённые строки всех запусков выбранного бота из базы; новые живые строки не вмешиваются в просмотр истории.

Границы фиксируются в момент выбора и отображаются над таблицей. **Обновить период** пересчитывает относительные интервалы; произвольные границы остаются прежними. Даты «Сегодня», «Вчера» и поля «От / До» используют часовой пояс браузера, указанный в форме. Начало включается в выборку, окончание не включается.

Первая страница содержит до 500 строк. **Загрузить более ранние** добавляет следующую страницу без потери уже загруженных строк. При диапазоне в несколько дней колонка времени также показывает дату. Поиск, фильтры и экспорт работают по загруженным строкам; очистка доступна в режиме текущего запуска.

Если логи удалены или не были сохранены, восстановить их выбором периода нельзя. Во вкладке отдельного исторического запуска по-прежнему показываются только его записи.

## Копирование и сохранение

Через **Опции** вывод можно скопировать или скачать:

| Формат | Когда удобен |
|--------|--------------|
| Текст | Простой просмотр и пересылка как обычного текста |
| JSON | Передача лога в другие инструменты для разбора |
| CSV | Открытие в таблицах для анализа строк |

## Масштаб и очистка

В **Опциях** — увеличить/уменьшить текст и очистить накопленные строки.

## Вкладки терминалов

Если запущено несколько ботов, между их терминалами можно переключаться через выбор терминала в шапке. Здесь же доступны не только живые терминалы работающих ботов, но и истории прошлых запусков — записи вывода уже завершённых сессий. Истории отмечены значком 📜 и датой запуска, поэтому их легко отличить от живых терминалов и вернуться к логам предыдущего запуска.
