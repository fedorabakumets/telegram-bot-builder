# Вкладка «Файлы»

Во вкладке собраны медиафайлы проекта: полученные от пользователей, отправленные ботами и загруженные вручную. Здесь можно найти файл, посмотреть его, скачать, скопировать Telegram ID, прикрепить к блоку или удалить.

## Проект, бот и источник

В шапке выберите проект и бота. Вариант **«Все боты»** показывает файлы без ограничения одним ботом проекта.

Переключатель под кнопками загрузки ограничивает список по источнику:

| Источник | Какие файлы показаны |
| --- | --- |
| Все | Файлы всех источников |
| Входящие | Медиа из сообщений пользователей |
| Исходящие | Медиа, отправленные ботом |
| Загруженные | Файлы, добавленные вручную |

При смене источника открывается первая страница и снимается выбор файлов.

**«Обновить»** загружает актуальный список. **«Документация»** открывает эту страницу на Docusaurus. На узких экранах подписи этих действий скрыты, остаются иконки.

Рядом с загрузкой показаны занятое место и лимит хранилища. Если ограничение не задано, отображается **«Без лимита»**.

## Загрузка

- **«Загрузить»** открывает выбор файлов на устройстве.
- Перетащите файлы с компьютера в область вкладки. При наведении появится подсказка **«Отпустите файлы для загрузки»**. Файлы попадут в выбранное хранилище проекта; пока идёт загрузка, новая пачка не принимается. Текст и ссылки не запускают загрузку.
- **«Из буфера»** позволяет добавить скопированные файлы. Если браузер не разрешает чтение буфера кнопкой, используйте **Ctrl+V**, **Ctrl+М** в русской раскладке или **Shift+Insert**.

При нескольких доступных хранилищах выберите место загрузки в соответствующем меню. После загрузки новые файлы отмечаются для дальнейших действий. Если до этого были открыты входящие или исходящие, вкладка переключается на **«Загруженные»**.

Загрузка в хранилище и прикрепление к блоку — отдельные действия. Чтобы бот отправлял загруженный файл из сценария, выберите блок и прикрепите файл к нему.

## Фильтры

Нажмите **«Фильтры»** и задайте один или несколько параметров:

| Поле | Что проверяется |
| --- | --- |
| Название файла | Совпадение с введённым фрагментом имени |
| Тип файла | Фото, видео, аудио, голосовое, документ, стикер, анимация (GIF), видеосообщение или обложка |
| Дата загрузки | Период с датами **«С»** и **«По»** |
| Сотрудник | Кто загрузил файл |
| Хранилище | Где сохранён файл |
| Размер файла | Минимальный и максимальный размер в KB или MB |

Можно указать только начало или конец периода. Дата **«По»** включает весь выбранный день. Границы размера также можно задавать независимо.

Изменения в окне являются черновиком: нажмите **«Применить фильтры»**, чтобы обновить список. Закрытие окна без применения не сохраняет черновик. **«Сбросить всё»** очищает применённые фильтры.

Если конечная дата раньше начальной или минимальный размер больше максимального, применение недоступно. Для неверного периода под датами появляется пояснение.

После применения на кнопке виден счётчик фильтров, а рядом — активные условия. Отдельное условие можно снять без повторного заполнения формы.

## Карточки и просмотр

Карточка содержит флажок выбора, миниатюру, название, тип, размер и дату. Рядом находятся **«Сведения о файле»**, скачивание и удаление.

Нажмите миниатюру, чтобы открыть доступное превью. В просмотре можно переходить между соседними файлами. Если прямое скачивание недоступно, соответствующее действие отключено.

Список адаптируется к ширине рабочей области: на узком экране элементы переносятся, на широком доступно табличное представление. Раскрытие сведений добавляет содержимое ниже верхней строки карточки.

### Сведения о файле

| Сведение | Значение |
| --- | --- |
| Хранилище | Telegram или хранилище загруженного файла |
| ID файла | Внутренний числовой ID записи конструктора |
| Отправитель | Telegram ID пользователя для входящего файла |
| Отправил | Имя и username бота для исходящего файла |
| Загрузил | Сотрудник, загрузивший файл вручную |
| Использование | Блоки текущего сценария, в которых найдено вложение |
| Telegram ID | Идентификаторы файла для отдельных ботов и кнопки копирования |

**«Открыть сообщение»** ведёт в диалоги к связанному сообщению. Для файла, загруженного вручную, такой ссылки нет.

**«Не найдено использование в блоках»** означает, что среди проверяемых блоков текущего сценария не найдены ссылки на файл. Это не означает отсутствие файла в хранилище или переписке.

Для исходящего файла с сохранённым блоком отправки доступна дополнительная строка **«Источник отправки»**. Она показывает исторический источник отправки, а не текущее прикрепление в сценарии. Если источник не сохранён, строка скрыта. Сохранённый блок может уже отсутствовать в текущем сценарии.

### Telegram ID и копирование

Telegram `file_id` — строковый идентификатор медиа, а не внутренний числовой ID записи. Для разных ботов у одного файла могут быть разные Telegram ID.

В сведениях показаны имена ботов и соответствующие значения. Нажмите сам ID или кнопку копирования рядом. Длинный ID может быть сокращён на экране, но копируется целиком. Если идентификаторов много, раскройте оставшиеся кнопкой **«Ещё»**.

## Прикрепление к блоку

1. Включите **«Прикрепление к блоку»**.
2. Введите текст блока, название листа или ID в поле **«Название или ID блока»**. Список результатов раскрывается при вводе и обновляется по мере набора.
3. Выберите подходящий блок из результатов. Для точного ID можно нажать **«Выбрать по ID»** или Enter. Список также открывается кнопкой **«Выберите блок из списка»**.
4. Отметьте файлы и нажмите **«Прикрепить (N)»** в панели действий над списком.

Результаты поиска встроены в форму: они сдвигают файлы вниз и не перекрывают карточки. Если совпадений нет, отображается **«Блоки не найдены»**. Поиск не меняет выбранный блок, пока вы не выберете результат или не примените точный ID.

В списке доступны только блоки, поддерживающие вложения. Варианты показывают текст блока, лист, ID и сведения о медиа. Неподходящий или неизвестный ID не принимается: под полем появляется ошибка.

Альтернативный путь — **«Выбрать блок на холсте»**. После выбора доступны переход к блоку и **«Сбросить блок»**. Для поддерживаемых фотографий выбранного блока показывается их просмотр.

Если файл выбирается через **«Из хранилища»** в свойствах блока, цель уже задана: отметьте файлы и подтвердите прикрепление.

## Выбор и удаление

Флажок слева отмечает один файл. **«Выбрать все (N)»** отмечает файлы только на текущей странице, а не во всём проекте. Повторное нажатие снимает отметки.

При выборе появляется панель со счётчиком **«Выбрано файлов»** и доступными действиями:

- **«Прикрепить (N)»** — доступно, когда выбран блок назначения.
- **«Удалить (N)»** — удаление отмеченных файлов.

Удаление одного файла через иконку корзины и массовое удаление требуют подтверждения. Для одного файла окно показывает его имя. **«Отмена»** закрывает подтверждение; у окна удаления одного файла также есть крестик. До подтверждения файлы не удаляются. Подтверждённое удаление нельзя отменить.

## Страницы списка

В **«Показывать по»** доступны 5, 10, 25, 50 и 100 файлов. Нижняя навигация показывает текущую страницу, количество страниц и диапазон записей. Стрелки переходят на соседнюю страницу; на границах соответствующая стрелка отключена.

При минимальной ширине второстепенные элементы нижней строки скрываются, чтобы оставить доступными номер страницы и стрелки. Выбор количества файлов остаётся над списком.
