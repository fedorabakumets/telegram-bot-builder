# Вкладка «Агент»

Вкладка «Агент» позволяет подключить Telegram Agent к вашему профилю и управлять доступом других ИИ клиентов. Подключения относятся к профилю пользователя, а не к отдельному проекту.

## Кнопки в заголовке

- **Документация** открывает это руководство в новой вкладке.
- **Обновить** повторно загружает подключения и токены. Обновление не создаёт токены и не меняет права доступа.

В узкой панели кнопки отображаются иконками с подсказками.

## Быстрый старт с Telegram Agent

1. Нажмите **Открыть в Telegram**. Откроется личный чат с [@botcraftstudiobot](https://t.me/botcraftstudiobot).
2. Напишите сообщение с задачей. Профиль подключается автоматически по Telegram ID; создавать токен вручную не требуется.
3. Укажите, с каким проектом и что нужно сделать.

Если профиля ещё нет, он создаётся автоматически и первоначально не содержит проектов. В группе начните сообщение со слова «агент», упомяните бота или ответьте на его сообщение. Ответы в группе видны её участникам.

## Управление подключением

Карточка показывает имя агента и состояние доступа.

- **Отключить** запрещает доступ и отзывает токены подключения.
- **Подключить снова** разрешает агенту получить новый доступ при следующем сообщении.

После отключения вернуть разрешение можно на этой вкладке. Команда `/logout` и удаление автоматического сервера также отключают доступ. Отзыв автоматического токена отключает связанное подключение.

## Другие ИИ клиенты

Раздел **Другие ИИ клиенты** предназначен для ручного подключения через MCP. Для каждого клиента создавайте отдельный токен, чтобы при необходимости отозвать только его доступ.

### Создание токена

1. Нажмите **Создать токен**.
2. Заполните обязательное поле **Название**, например «Cursor на ноутбуке». Пустое название и одни пробелы не принимаются.
3. Выберите **Срок действия**: без ограничения, 30 или 90 дней.
4. Проверьте права: создаваемый токен позволяет читать и изменять проекты вашего профиля.
5. Нажмите **Создать токен** и скопируйте значение в настройки клиента.

Полный токен показывается только один раз после создания. В списке остаётся его префикс. Не публикуйте токен и не передавайте его другим пользователям.

### Список токенов и отзыв доступа

У токена показаны название, префикс, права, время создания и последнего использования. Если обращений ещё не было, указано **Ещё ни разу**.

Нажмите **Отозвать доступ** у ненужного токена и подтвердите действие. Для повторного ручного подключения потребуется новый токен. Пустой список предлагает создать первое подключение.

## Ошибки

Если подключение не работает, нажмите **Обновить** и проверьте состояние доступа. Убедитесь, что токен ручного клиента не отозван и его срок не истёк. Перед повтором задачи после временной ошибки проверьте, не успела ли предыдущая операция изменить проект.

При ошибке загрузки списка вкладка показывает сообщение с предложением обновить страницу. Ошибка создания токена отображается в форме: исправьте поле или повторите запрос после устранения причины.
