# Агент

Для Bot Builder Agent достаточно написать задачу в личном чате. Если профиля ещё нет,
он создаётся автоматически и не содержит проектов. В группе откройте личный чат агента.
Кнопка «Открыть в Telegram» в карточке Telegram Agent открывает личный чат
[@botcraftstudiobot](https://t.me/botcraftstudiobot) в новой вкладке.

Во вкладке показаны автоматические подключения и их состояние. «Отключить» отзывает
все токены этого подключения. «Подключить снова» разрешает агенту получить новый доступ
при следующем сообщении. Команда `/logout` и удаление автоматического сервера также
отключают доступ. При временной ошибке повторите запрос позже, предварительно проверив
результат изменяющей операции.

Кнопка «Создать токен» нужна для других MCP-клиентов и ручных подключений.
Отзыв автоматического токена отключает всё связанное подключение.
