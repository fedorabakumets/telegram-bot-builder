# Настройки рантайма в админке

Длинный список переменных окружения настраивается в панели `/admin`. В боковом меню шесть разделов: хранилища, бэкапы, воркеры, исполнители, сборки и площадка.

Пока поле не сохранено, сервер читает живой `process.env`. После сохранения значение из админки важнее. Пустое обычное поле удаляет запись и снова включает запасной вариант из окружения.

В полях ввода серый пример — это placeholder: он не подставляется в значение и не уходит при сохранении. Подсказка под полем по-прежнему поясняет смысл. Под заголовком раздела, рядом с подзаголовком, есть ссылка на документ этого раздела. Она открывает текст во встроенном просмотре `/admin/guides/…` (загрузки в S3, бэкапы, воркеры, исполнитель, сборки, доступ ботов к базе и соседние документы площадки).

## Что остаётся в окружении

Эти переменные в админку не переносятся: без них процесс не стартует и не открывает базу.

- `DATABASE_URL`
- `SESSION_SECRET`
- `ADMIN_API_KEY`
- `PORT`
- `HOST`
- `NODE_ENV`
- `STORAGE_ENCRYPTION_KEY`

Старые имена остальных переменных по-прежнему работают как запасной вариант. В `.env.example` они не перечислены.

## Секреты

Ключи S3, токены, адрес Redis исполнителя, список чужих баз и `BOT_DATABASE_URL` в форме не показываются. В ответе API у секрета только признак «уже задан». Пустое поле секрет не стирает. Сохранённый секрет лежит в таблице `app_settings` (ключ `runtime.<ИМЯ>`) и в памяти процесса. В `process.env` он не копируется, поэтому базовая среда воркера его не наследует.

`SUPPORT_BOT_TOKEN` дополнительно пишется в прежний ключ `support_bot_token`.

## Хранилища и бэкапы

Сохранение раздела «Хранилища» создаёт или обновляет строку `s3-default`. Новые ключи шифруются `STORAGE_ENCRYPTION_KEY`. Если ключа шифрования нет, ключи открытым текстом не записываются. Пустые поля ключей оставляют прежний `secretsEnc`.

Бэкап не пишется в публичное хранилище: `local-default`, каталог `uploads` и бакет с `publicUrlBase`. Такие пункты в списке недоступны. Без выбранного хранилища дамп идёт в папку `.db-backups`. Интервал `0` выключает расписание. Кнопка «Снять сейчас» делает дамп сразу. Сохранение раздела бэкапов перезапускает планировщик без рестарта процесса.

## Документация в панели

Инструкции рантайма, справочник API, схема базы и инструкция BotFather открывают опубликованный сайт GitHub Pages во фрейме. Кнопка «Назад» возвращает в панель или соответствующий раздел настроек. Для просмотра нужен доступ к сайту документации.

Docker не генерирует документацию и не включает каталоги `docs/` и `docs-site/` в контекст сборки. OpenAPI JSON и интерактивные интерфейсы API продолжают работать: спецификация собирается сервером из кода маршрутов. Обновления статей публикуются отдельно от образа приложения.
