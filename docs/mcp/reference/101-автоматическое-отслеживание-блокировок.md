# Автоматическое отслеживание блокировок

Настройка токена `trackUserBlocks` (по умолчанию `1`) включает обработку Telegram-событий
`my_chat_member` в личных чатах. Генератор сохраняет блокировку/разблокировку пользователя
и системное событие для ленты диалога. Эта настройка относится к токену, а не к JSON нод.
`trackGroupMembership` (по умолчанию `1`) отдельно включает такие события для групп:
«Бота добавили в группу» и «Бота исключили из группы». Каналы не входят.
