# MCP пользовательских таблиц

Инструменты читают и меняют только таблицы, созданные в проекте (`bot_tables`). Списки пользователей, сообщений, переменных, групп, файлов, рассылок и журналов сюда не входят.

Ключ ячейки — **числовой идентификатор столбца строкой**. Имя столбца лежит рядом в `db_get_table` и `db_list_table_columns`. Пустая строка в ячейке сохраняется. Неизвестный идентификатор столбца отклоняется.

## Чтение

Доступно локально и по удалённому адресу.

| Инструмент | Что делает |
|------------|------------|
| `db_list_tables` | Список таблиц проекта |
| `db_find_tables` | Поиск по части имени |
| `db_get_table` | Таблица, столбцы и сводка |
| `db_list_table_columns` | Столбцы: `id`, имя, позиция |
| `db_list_table_rows` | Страница строк, по умолчанию 100, не больше 500 |
| `db_get_table_row` | Одна строка |
| `db_find_table_rows` | До пяти условий |
| `db_count_table_rows` | Количество по тем же условиям |
| `db_get_table_summary` | Сколько строк и непустых ячеек |

Сортировка: `id`, `row_index` или `column:<id>`. Операторы: `equals`, `not_equals`, `contains`, `starts_with`, `ends_with`, `filled`, `empty`, `greater_than`, `less_than`.

## Изменения

| Инструмент | Подтверждение |
|------------|----------------|
| `db_create_table`, `db_rename_table` | нет; имя `_content` запрещено |
| `db_delete_table` | `confirm: true`, иначе сеть не вызывается |
| `db_add_table_column`, `db_rename_table_column`, `db_reorder_table_columns` | нет |
| `db_delete_table_column` | `confirm: true` |
| `db_add_table_rows` | не больше 200 строк |
| `db_update_table_row` | полная замена ячеек |
| `db_patch_table_row` | только переданные ячейки |
| `db_delete_table_row`, `db_clear_table_rows` | `confirm: true` |
| `db_reindex_table_rows` | нумерация с нуля |
| `db_import_table_rows` | `replace` требует `confirm: true` |
| `db_apply_table_ops` | до 50 операций; удаление требует `confirm: true` |

Пакет выполняется одной транзакцией. При ошибке всё откатывается, в ответе есть `failed_op_index`. Уведомление об изменении отправляется один раз после успешной записи.

Строки `_content` по-прежнему можно править: сценарий обновляется, а саму таблицу нельзя переименовать или удалить.

Ответы `401`, `403` и `500` приходят как `HTTP <код>` без тела сервера.

## Файлы

Только у локального помощника. Удалённый адрес этих инструментов не получает.

| Инструмент | Формат |
|------------|--------|
| `db_import_table_file` | CSV или JSON из рабочего каталога либо временной папки |
| `db_export_table` | CSV, JSON или JSONL во временный закрытый каталог |
| `db_export_project_tables` | общий JSON версии 1 или JSONL |
| `db_import_project_tables` | JSON версии 1: без `confirm` только превью |

Путь выгрузки выбирает сервер. Ссылки, чужие каталоги и файлы больше 5 МБ отклоняются. Замена существующих строк и таблиц требует `confirm: true`.
