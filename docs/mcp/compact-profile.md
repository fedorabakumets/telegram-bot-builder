# Компактный профиль MCP

Результаты записи, ревизии, повторы, миграции и возврат к полному профилю
описаны в [правилах надёжной работы](reliability.md).

Профиль выбирает оператор сервера переменной `BOTCRAFT_MCP_PROFILE`:

- `full` (по умолчанию) сохраняет отдельные инструменты и добавляет каталог.
- `compact` публикует только четыре инструмента каталога.

Для stdio задайте переменную в окружении процесса MCP. Для HTTP задайте её
в окружении приложения и перезапустите сервер. Настройка HTTP действует
на всех клиентов этого экземпляра; параметр запроса её не переопределяет.
Неизвестное значение считается ошибкой настройки.

## Последовательность работы

1. `list_sections` показывает разделы и количество доступных действий.
2. `search_actions` находит действия по имени, описанию и разделу; для
   продолжения списка используйте возвращённый курсор.
3. `describe_actions` возвращает точные контракты выбранных действий.
4. `call_action` выполняет действие по его `action_id` и объекту `args`.

Идентификаторы действий совпадают с именами существующих инструментов.
Перед незнакомой операцией запрашивайте её схему. Перед изменением сценария
читайте правила соответствующей ноды и проверяйте реальные ID проекта.

## Совместимость и ограничения

Каталог строится из фактических регистраций MCP. Отдельный HTTP-маршрут
или произвольный URL вызвать через него нельзя. Схемы и обработчики общие
для полного и компактного профилей; авторизация и ограничения обработчиков
сохраняются. Удалённый профиль не включает локальные файловые инструменты.

Компактный профиль сокращает публикуемый `tools/list`, но требует отдельных
вызовов поиска и описания схем. Он не делает широкие поля существующих
контрактов более строгими и не исправляет автоматически ограничения
существующих обработчиков. Полный переход на компактный режим следует
оценивать по задачам конкретного MCP-клиента.

OpenAPI MCP остаётся отдельным адаптером. Его генератор сохраняет публичные
операции и разрешённые альтернативы PAT; неподдерживаемая авторизация
останавливает генерацию вместо автоматического расширения доступа.
