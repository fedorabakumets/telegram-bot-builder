# Отладка и логи

Для live-бота начни с `db_bot_status`, затем вызови `db_bot_logs` или `db_search_bot_logs`. Сопоставляй вход пользователя, ожидаемую ноду, переменные и фактический результат.

Полного replay и dry-run для Telegram пока нет. Не утверждай, что сценарий проверен в runtime, если проверен только JSON. После исправления перечитай проект, вызови валидатор и повтори проверку логов.
