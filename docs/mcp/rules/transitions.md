# Переходы

`autoTransitionTo` ведёт дальше после завершения текущей ноды. `inputTargetNodeId` срабатывает после получения ответа. `goto` является действием кнопки и ведёт на её `target`.

Не смешивай автоматический переход и кнопку без явной логики. После изменения проверяй цели, входящие связи через `db_find_inbound` и навигацию через `db_report_button_navigation`.
