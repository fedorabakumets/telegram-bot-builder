# `db_import_table_rows`

## Назначение

Импортирует до 200 строк из JSON-аргумента. `append` добавляет строки, `replace` заменяет все строки и требует `confirm: true` ещё до обращения к API.

## Когда использовать

Перед вызовом получи ID столбцов через `db_list_table_columns`. Для `replace` сначала запроси подтверждение пользователя; без него операция не отправляется.

## Параметры

- `project_id` — number; обязательный параметр.
- `table_id` — number; обязательный параметр.
- `mode` — `append | replace`; обязательный параметр.
- `confirm` — boolean; необязательный параметр.
- `rows` — array; обязательный параметр.

Точные типы и обязательность берутся из схемы MCP-регистрации. Перед вызовом проверь описание инструмента в MCP-клиенте; не придумывай отсутствующие поля.

## Пример вызова

```json
{
  "tool": "db_import_table_rows",
  "arguments": { "project_id": 42, "table_id": 12, "mode": "append", "rows": [ { "101": "Анна", "102": "Новый" } ] }
}
```

## Пример успешного ответа

Ответ содержит результат импорта. Проверь фактические строки через `db_list_table_rows`, особенно после большого пакета.

## Типичные ошибки

- В массиве больше 200 строк.
- Ключ строки не является ID существующего столбца строкой.
- `replace` вызван без `confirm: true`.

## Ограничения и безопасность

Тул изменяет содержимое таблицы. Не используй `replace` для теста без резервного экспорта.
- Не трактуй отсутствие ошибки транспорта как подтверждение бизнес-корректности результата.
- Для дальнейшего изменения используй отдельный mutating-тул после проверки данных.
