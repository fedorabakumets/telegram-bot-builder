# `create_node`

## Назначение

Создать одну ноду с дефолтами конструктора (get_node_schema перед незнакомым типом). Для command_trigger: только латиница (/buy, /refund), не /купить

## Когда использовать

Используй для добавления одной ноды: тул сам создаёт дефолтный `data`. Перед незнакомым типом сначала вызови `get_node_schema` и `get_node_example`.

## Параметры

- `type` — string; обязательный параметр.
- `partial_data` — object; необязательный merge-патч полей `data`.
- `id` — string; необязательный уникальный ID ноды.
- `position` — `{x: number, y: number}`; необязательная позиция на холсте.

Точные типы и обязательность берутся из схемы MCP-регистрации. Перед вызовом проверь описание инструмента в MCP-клиенте; не придумывай отсутствующие поля.

## Пример вызова

```json
{
  "tool": "create_node",
  "arguments": {
    "type": "input",
    "partial_data": { "inputVariable": "email", "validationType": "email" },
    "id": "input-email",
    "position": { "x": 420, "y": 180 }
  }
}
```

## Пример успешного ответа

Ответ содержит готовую ноду с `id`, `type`, `position` и полным `data`. Это ещё не запись в проект.

## Типичные ошибки

- Переданы неизвестные или пропущенные обязательные параметры.
- Тип не разрешён MCP или не существует в палитре.
- `partial_data` содержит поле, которого нет в схеме ноды.
- ID уже используется в проекте.
- Нода создана, но не подключена к следующему переходу.

## Ограничения и безопасность

Тул может изменять live-БД, проект или состояние бота. Выполняй его только в рамках явной просьбы пользователя и проверь результат после операции.
- Не перезапускай бота автоматически; перезапуск допустим только по явной просьбе пользователя.
- После операции перечитай состояние и вызови подходящую проверку или логи.
- Если тул требует `confirm`, передавай его только после подтверждения пользователя.

## Связанные инструменты

- `get_tool_docs` — получить карточку этого и связанных тулов.
- `search_tool_docs` — найти подходящие инструменты.
- `get_workflow_docs` — получить рекомендуемую последовательность действий.

## Рекомендуемый следующий шаг

Проверь результат через `validate_node`, добавь ноду в проект, подключи её через `connect_nodes` и запусти `validate_bot_project`.
