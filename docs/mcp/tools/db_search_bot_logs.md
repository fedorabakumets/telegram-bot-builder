# `db_search_bot_logs`

## Назначение

Ищет сохранённые логи по проекту, токену, ISO-периоду, тексту и типу записи. История ограничена сроком хранения; read-only.

## Когда использовать

Используй для расследования ошибок, которые уже исчезли из live-вывода, или поиска исключения после запуска.

## Параметры

- `project_id` — positive integer; обязательный.
- `token_id` — positive integer; обязательный.
- `from`/`to` — ISO datetime с timezone; обязательный период.
- `text` — string до 500 символов; необязательный поиск.
- `type` — `stdout | stderr | status`; необязательный тип.
- `before_id` — positive integer; необязательный курсор.
- `limit` — integer 1–1000; необязательный размер ответа.

Точные типы и обязательность берутся из схемы MCP-регистрации. Перед вызовом проверь описание инструмента в MCP-клиенте; не придумывай отсутствующие поля.

## Пример вызова

```json
{
  "tool": "db_search_bot_logs",
  "arguments": { "project_id": 42, "token_id": 7, "from": "2026-10-25T00:00:00+03:00", "to": "2026-10-25T23:59:59+03:00", "type": "stderr", "text": "Traceback", "limit": 100 }
}
```

## Пример успешного ответа

Ответ содержит найденные записи и метаданные страницы. Для старых записей передавай `before_id` из предыдущего ответа.

## Типичные ошибки

- `from`/`to` не являются ISO datetime с timezone.
- `limit` вне диапазона 1–1000.
- Период старше срока хранения не даст результатов.

## Ограничения и безопасность

Тул только читает данные или выполняет проверку; он не должен изменять проект, БД или состояние бота.
- Не трактуй отсутствие ошибки транспорта как подтверждение бизнес-корректности результата.
- Для дальнейшего изменения используй отдельный mutating-тул после проверки данных.

## Связанные инструменты

- `get_tool_docs` — получить карточку этого и связанных тулов.
- `search_tool_docs` — найти подходящие инструменты.
- `get_workflow_docs` — получить рекомендуемую последовательность действий.

## Рекомендуемый следующий шаг

Используй найденный traceback для исправления ноды, затем проверь проект и повтори сценарий.
