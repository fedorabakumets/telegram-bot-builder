# `db_add_table_rows`

## Назначение

Добавляет до 200 строк в пользовательскую таблицу. Ключи `data` — числовые ID столбцов, записанные строками; чужой ключ отклоняется до записи.

## Когда использовать

Сначала вызови `db_get_table` или `db_list_table_columns`, чтобы получить настоящие `table_id` и ID столбцов. Операция изменяет данные, но подтверждение для добавления не требуется.

## Параметры

- `project_id` — number; обязательный параметр.
- `table_id` — number; обязательный параметр.
- `rows` — array; обязательный массив максимум из 200 объектов.
- `rows[].row_index` — integer; необязательный индекс строки.
- `rows[].data` — object; обязательная карта `"column_id": "текст"`.

Точные типы и обязательность берутся из схемы MCP-регистрации. Перед вызовом проверь описание инструмента в MCP-клиенте; не придумывай отсутствующие поля.

## Пример вызова

```json
{
  "tool": "db_add_table_rows",
  "arguments": {
    "project_id": 42,
    "table_id": 12,
    "rows": [
      { "row_index": 0, "data": { "101": "Анна", "102": "anna@example.com" } },
      { "data": { "101": "Иван", "102": "ivan@example.com" } }
    ]
  }
}
```

## Пример успешного ответа

Ответ содержит результат записи и созданные строки/ID. После записи перечитай нужный диапазон через `db_list_table_rows`.

## Типичные ошибки

- `rows` отсутствует или содержит больше 200 строк.
- Ключ `data` не является числовым ID существующего столбца.
- Значение не строка или таблица относится к другому проекту.

## Ограничения и безопасность

Тул может изменять live-БД, проект или состояние бота. Выполняй его только в рамках явной просьбы пользователя и проверь результат после операции.
- Не перезапускай бота автоматически; перезапуск допустим только по явной просьбе пользователя.
- После операции перечитай состояние и вызови подходящую проверку или логи.
- Если тул требует `confirm`, передавай его только после подтверждения пользователя.
