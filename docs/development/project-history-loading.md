# Загрузка истории проектов

Список истории получает из PostgreSQL только метаданные: идентификатор, метку,
автора, вид версии и время создания. JSONB-снимок `snapshot` в запрос списка не
включается. Все сохранённые версии остаются в БД; изменение не вводит удаление
истории или новые сроки хранения.

## API

`GET /api/projects/{id}/versions` без параметров сохраняет прежний ответ-массив
метаданных для совместимости, в том числе с MCP.

Для постраничной загрузки передайте `limit` от 1 до 100:

```http
GET /api/projects/42/versions?limit=25
```

Ответ содержит `items`, `nextCursor` и `total`. Следующая страница использует
полученный `nextCursor` вместе с `limit` для того же проекта; при передаче только
`cursor` размер страницы равен 20. Курсор непрозрачный:
клиент не должен собирать или изменять его. Неверные параметры возвращают HTTP 400.
Доступ к проекту проверяется существующим middleware.

Порядок: `createdAt DESC NULLS LAST`, затем `id DESC`. Курсор сохраняет точность
времени PostgreSQL и различает одинаковые даты. Страницы не являются одной
транзакционной копией истории: при изменениях списка клиент начинает загрузку заново.

Полный снимок запрашивается отдельно по идентификатору версии для сравнения или
восстановления. Эти действия сохраняют прежние проверки доступа и поведение.

## Интерфейс

Кнопка истории на холсте загружает список после открытия. Основная панель истории
получает страницы с сервера; пагинация не загружает все снимки в браузер или backend.
Изменение проекта и размера страницы сбрасывает навигацию. После сохранения,
удаления или восстановления список инвалидируется через прежний ключ запросов.

## Проверка эффекта и откат

Проверяйте число запросов с закрытой и открытой историей, размер SQL-результата,
порядок страниц, сравнение и восстановление старых версий. Падение RAM не
гарантируется: уже прочитанные страницы могут оставаться в файловом кэше ОС.
Доступные подключения, бэкапы и другая нагрузка влияют на замеры независимо.

Откат выполняется возвратом кода клиента и API; миграция данных не требуется.
Снимки, метки, авторы и даты версий сохраняются.
