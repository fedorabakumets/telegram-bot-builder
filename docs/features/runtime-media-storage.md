# Доступ бота к медиа из хранилища

Сервер выдаёт зарегистрированные файлы проекта через `/api/runtime/media` по отдельному токену проекта. Токен вычисляется из `MEDIA_RUNTIME_SECRET` панели; секрет должен быть стабильным и содержать не менее 32 символов. В рабочий процесс передаются только производный токен, адрес панели и ID проекта. Смена секрета делает ранее выданные токены недействительными и требует перезапуска процессов с новыми токенами.

На Linux локальное чтение требует доступного `/proc/self/fd`: после открытия проверяется путь самого дескриптора. На Windows отдельный процесс PowerShell открывает файл, проверяет конечный путь открытого дескриптора через `GetFinalPathNameByHandleW` и передаёт данные из этого же дескриптора. Для его работы необходим встроенный Windows PowerShell и разрешение выполнять входящий в приложение скрипт. Объект повторно открывается с проверкой версии перед отправкой. На остальных платформах локальное чтение этим маршрутом закрыто. Подробнее об API: [документация Microsoft](https://learn.microsoft.com/en-us/windows/win32/api/fileapi/nf-fileapi-getfinalpathnamebyhandlew).
