# Railway: tbb-panel

`.railway/railway.ts` описывает действующие сервисы, базы данных, хранилища, тома и фильтры изменений окружения `production`. Файл импортирован из Railway 11 ноября 2026 года. Перед изменением инфраструктуры сверяйте его с фактическим состоянием проекта.

Переменные окружения не управляются через IaC (`variables: { managed: false }`). Секреты остаются в Railway и не попадают в репозиторий.

`tbb-backups` не входит в конфигурацию `production`: это хранилище зарезервировано для резервных копий VPS и не создаётся при применении IaC.

## Проверка и применение

1. Привяжите каталог к проекту `tbb-panel` и окружению `production`: `railway link --project 21c0b471-1a5d-4670-a913-1171752cb7bb --environment ea4610c5-7c0c-4c5b-9daf-02f45459ac95`.
2. Установите зависимости: `npm ci`.
3. Посмотрите изменения: `railway config plan`.
4. Применяйте только проверенный план: `railway config apply`.

Для IaC нужен Railway CLI версии не ниже 5.42.1. На Windows при ошибочном сообщении об устаревшем CLI проверьте, что переменная `_` указывает на исполняемый файл Railway CLI, а не на оболочку `railway.ps1`.

Старые `railway*.toml` остаются в репозитории для переходного периода. Railway прекращает читать Config as Code 1 декабря 2026 года. После применения IaC их можно удалить отдельным изменением, сверив настройки каждого сервиса.
