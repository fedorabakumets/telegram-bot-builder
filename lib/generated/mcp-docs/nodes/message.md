# Message-нода

`message` отправляет текст или медиа, но не ждёт ответ. Кнопки и клавиатура **не настраиваются внутри message**: их нужно создавать отдельной `keyboard`-нодой и соединять с сообщением. Для ожидания следующего сообщения используй отдельную `input`-ноду.

Тексты поддерживают `{переменные}`; `{{переменная}}` и `${переменная}` не используют.

```json
{"type":"message","data":{"messageText":"Привет, {first_name}!"}}
```

Пример связки: `message` → `keyboard` → следующая нода. Если кнопки не нужны, переходи из `message` напрямую. Не добавляй в `message` поля `buttons`, `keyboardType` или поля ожидания ввода, если их нет в фактической схеме конкретной версии.

Проверь форматирование и `autoTransitionTo` через `get_node_schema`. Встроенные поля сбора ввода в `message` не добавляй.

## Связанные ноды

`keyboard` отвечает за кнопки и клавиатуру, `input` — за ожидание ответа пользователя, `condition` и `code` — за дальнейшую логику.

## Как проверить результат

Вызови `get_node_schema(message)`, `get_node_example(message)` и `validate_node`, затем проверь связку `message` → `keyboard` вручную.
