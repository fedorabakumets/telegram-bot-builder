# Message-нода

`message` отправляет текст или медиа, но не ждёт ответ. Для ожидания следующего сообщения используй отдельную `input`-ноду. Тексты поддерживают `{переменные}`; `{{переменная}}` и `${переменная}` не используют.

```json
{"type":"message","data":{"messageText":"Привет, {first_name}!","keyboardType":"none","buttons":[]}}
```

Проверь форматирование, клавиатуру и `autoTransitionTo` по `get_node_schema`. Встроенные поля сбора ввода в message не добавляй.
