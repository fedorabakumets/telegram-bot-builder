# Bot table-нода

`bot_table` выполняет CRUD-операции с пользовательскими таблицами. Для простого чтения и записи предпочитай её `psql_query`; сложные JOIN и агрегации оставляй SQL-ноде.

После пустого чтения проверяй результат через `condition` с `is_empty` и не полагайся на старое значение переменной. Перед `decrement` проверяй, что значение не уйдёт в минус.
