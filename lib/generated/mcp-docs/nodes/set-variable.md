# Set variable-нода

`set_variable` создаёт, преобразует или вычисляет пользовательские переменные без Python-кода. Имя переменной указывается без скобок, а в текстах используется `{name}`.

Для простых преобразований предпочитай `set_variable`; `code` нужен для сложной логики, внешних API и async-операций. После присваивания следующая нода видит результат предыдущего assignment.
