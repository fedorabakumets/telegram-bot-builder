# Верхний уровень (BotDataWithSheets)

```json
{
  "version": 2,
  "activeSheetId": "sheet-id",
  "sheets": [ ...листы... ]
}
```

| Поле | Тип | Описание |
|------|-----|----------|
| `version` | number | Версия формата, всегда `2` |
| `activeSheetId` | string | ID активного листа |
| `sheets` | Sheet[] | Массив листов холста |
