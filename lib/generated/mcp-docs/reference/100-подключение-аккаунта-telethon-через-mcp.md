# Подключение аккаунта Telethon через MCP

Ноды `userbot_*` описывают сценарий; они не авторизуют аккаунт. Для конкретных `project_id` и `token_id` сначала сохраните API ID и API Hash через `db_set_userbot_settings` (`enabled: 0` до завершения входа), затем последовательно вызовите `db_userbot_send_code`, `db_userbot_sign_in` и, только при `needs_2fa: true`, `db_userbot_sign_in_2fa`. Не передавайте маски как новые секреты. Пропущенные настройки сохраняются; API Hash при отправке кода можно не указывать, если он сохранён. После успешного входа сессия сохраняется сервером и режим включается. Настройки применяются при следующем запуске: используйте `db_start_bot` или `db_restart_bot`, автоматического перезапуска нет. Если передана готовая сессия через настройки с `enabled: 1`, шаги входа не нужны. Не включайте секреты в сообщения и отчёты. При истёкшем коде начните с отправки нового; после перезапуска сервера незавершённый вход тоже начинается заново. Полное описание: docs/mcp/bot-builder.md.
