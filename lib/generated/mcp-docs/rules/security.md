# Безопасность

Read-only MCP-тулы не меняют проект. Live- и destructive-тулы могут менять БД, токены или состояние бота и выполняются только по явной просьбе пользователя.

Не раскрывай токены и секреты. Перед удалением, массовой операцией, стартом или остановкой проверь `project_id`, `token_id` и обязательный `confirm`. После операции перечитай состояние и проверь логи.
