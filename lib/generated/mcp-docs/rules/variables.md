# Переменные и контекст

## Для человека

В текстах и полях сценария переменные пишутся через одну пару фигурных скобок: `{name}`. Форматы `{{name}}` и `${name}` для подстановки Bot Builder не используй.

## Для агента

Имя переменной в поле сохранения указывается без скобок: `answer`. В сообщении — `{answer}`. Значение обычно хранится в пользовательском контексте и доступно следующим нодам текущего диалога; постоянное хранение требует соответствующей ноды или флага сохранения в БД.

Системные переменные (`{user_id}`, `{first_name}`, `{button_text}` и другие) создаются runtime. Пользовательские переменные создаются `input`, `code`, `set_variable`, `bot_table` и специализированными нодами.

## Проверка

Если переменная не раскрылась, проверь имя, ноду записи, порядок переходов и контекст пользователя. Не переименовывай переменную между нодами без обновления всех ссылок.
