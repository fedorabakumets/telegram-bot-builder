# Команды

`command_trigger.command` содержит только латинские буквы, цифры и `_`: `/start`, `/buy`, `/my_shop`. Кириллица в команде запрещена. Описание и тексты сообщений могут быть русскими.

Для аргументов одной строки используй `saveCommandArgsTo`; `/donate 777` сохранит `777` в указанную переменную. После изменения команды проверь уникальность и переход.
