# `db_create_table`

## Назначение

Создаёт пользовательскую таблицу проекта для использования в `bot_table`-ноде. Имя `_content` зарезервировано.

## Когда использовать

Используй, если подходящей таблицы нет. Операция изменяет БД проекта; после создания добавь столбцы через `db_add_table_column`.

## Параметры

- `project_id` — number; обязательный параметр.
- `name` — string; обязательный параметр.

Точные типы и обязательность берутся из схемы MCP-регистрации. Перед вызовом проверь описание инструмента в MCP-клиенте; не придумывай отсутствующие поля.

## Пример вызова

```json
{
  "tool": "db_create_table",
  "arguments": { "project_id": 42, "name": "Заказы" }
}
```

## Пример успешного ответа

Успешный ответ содержит созданные `table_id` и имя. Используй возвращённый ID, а не угадывай его.

## Типичные ошибки

- Переданы неизвестные или пропущенные обязательные параметры.
- Имя пустое или уже занято.
- Использовано зарезервированное имя `_content`.
- `project_id` недоступен текущему MCP-токену.

## Ограничения и безопасность

Тул только читает данные или выполняет проверку; он не должен изменять проект, БД или состояние бота.
- Не трактуй отсутствие ошибки транспорта как подтверждение бизнес-корректности результата.
- Для дальнейшего изменения используй отдельный mutating-тул после проверки данных.

## Связанные инструменты

- `get_tool_docs` — получить карточку этого и связанных тулов.
- `search_tool_docs` — найти подходящие инструменты.
- `get_workflow_docs` — получить рекомендуемую последовательность действий.

## Рекомендуемый следующий шаг

Получив `table_id`, добавь столбцы, проверь их через `db_get_table`, затем настрой `bot_table`-ноду.
