# `db_list_table_rows`

## Назначение

Возвращает страницу строк таблицы. `limit` по умолчанию 100, максимум 500; сортировка поддерживает `id`, `row_index` или `column:<id>`.

## Когда использовать

Используй для проверки результата `bot_table`, импорта или обновления строк. Для поиска по значениям используй `db_find_table_rows`.

## Параметры

- `project_id` — number; обязательный параметр.
- `table_id` — number; обязательный параметр.
- `limit` — number; необязательный параметр.
- `offset` — number; необязательный параметр.
- `sort` — string; необязательный параметр.
- `columns` — array; необязательный параметр.

Точные типы и обязательность берутся из схемы MCP-регистрации. Перед вызовом проверь описание инструмента в MCP-клиенте; не придумывай отсутствующие поля.

## Пример вызова

```json
{
  "tool": "db_list_table_rows",
  "arguments": { "project_id": 42, "table_id": 12, "limit": 50, "offset": 0, "sort": "column:101", "columns": [101, 102] }
}
```

## Пример успешного ответа

Ответ содержит строки и параметры страницы. `columns` ограничивает возвращаемые столбцы, но не меняет таблицу.

## Типичные ошибки

- Переданы неизвестные или пропущенные обязательные параметры.
- `limit` вне диапазона 1–500 или отрицательный `offset`.
- Сортировка ссылается на отсутствующий ID столбца.
- Агент принял первую страницу за полный набор данных.

## Ограничения и безопасность

Тул только читает данные или выполняет проверку; он не должен изменять проект, БД или состояние бота.
- Не трактуй отсутствие ошибки транспорта как подтверждение бизнес-корректности результата.
- Для дальнейшего изменения используй отдельный mutating-тул после проверки данных.
