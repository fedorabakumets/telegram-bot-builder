# `add_node`

## Назначение

Добавляет одну готовую ноду в переданный `project.json` и возвращает обновлённый JSON. Инструмент не пишет live-БД.

## Когда использовать

Используй для локальной сборки проекта: сначала получи ноду через `create_node`, проверь её через `validate_node`, затем добавь сюда. Для live-проекта используй `db_add_node`.

## Параметры

- `project_json` — union; обязательный параметр.
- `node` — record; обязательный параметр.
- `sheet_id` — string; необязательный параметр.

Точные типы и обязательность берутся из схемы MCP-регистрации. Перед вызовом проверь описание инструмента в MCP-клиенте; не придумывай отсутствующие поля.

## Пример вызова

```json
{
  "tool": "add_node",
  "arguments": {
    "project_json": { "version": 2, "nodes": [], "edges": [] },
    "node": { "id": "hello", "type": "message", "position": { "x": 0, "y": 0 }, "data": { "messageText": "Привет", "buttons": [], "keyboardType": "none" } }
  }
}
```

## Пример успешного ответа

Успешный ответ содержит новый `project_json`. Перед передачей в `save_project` или `update_project_db` снова вызови `validate_bot_project`.

## Типичные ошибки

- Переданы неизвестные или пропущенные обязательные параметры.
- ID ноды уже существует.
- Нода не соответствует схеме своего типа.
- Указан отсутствующий `sheet_id` или неверный формат проекта.

## Ограничения и безопасность

Тул может изменять live-БД, проект или состояние бота. Выполняй его только в рамках явной просьбы пользователя и проверь результат после операции.
- Не перезапускай бота автоматически; перезапуск допустим только по явной просьбе пользователя.
- После операции перечитай состояние и вызови подходящую проверку или логи.
- Если тул требует `confirm`, передавай его только после подтверждения пользователя.

## Связанные инструменты

- `get_tool_docs` — получить карточку этого и связанных тулов.
- `search_tool_docs` — найти подходящие инструменты.
- `get_workflow_docs` — получить рекомендуемую последовательность действий.

## Рекомендуемый следующий шаг

Проверь полный JSON, добавь необходимые связи через `connect_nodes`, затем проверь проект целиком.
