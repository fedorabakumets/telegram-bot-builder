# `db_set_userbot_settings`

## Назначение

Частично обновляет настройки Telethon Userbot для конкретного проекта и токена. Пропущенные поля не меняются; пустые и замаскированные секреты сохраняются. Автоматического перезапуска нет.

## Когда использовать

Используй перед авторизацией Userbot или для включения/выключения режима. Для входа сначала сохрани `api_id` и `api_hash`, затем пройди шаги отправки кода и входа.

## Параметры

- `project_id` — number; обязательный ID проекта.
- `token_id` — number; обязательный ID токена из `db_list_bot_tokens`.
- `enabled` — `0 | 1`; обязательный флаг режима.
- `api_id` — string или null; необязательный API ID.
- `api_hash` — string или null; необязательный секрет.
- `session_string` — string или null; необязательная готовая сессия.

Точные типы и обязательность берутся из схемы MCP-регистрации. Перед вызовом проверь описание инструмента в MCP-клиенте; не придумывай отсутствующие поля.

## Пример вызова

```json
{
  "tool": "db_set_userbot_settings",
  "arguments": { "project_id": 42, "token_id": 7, "enabled": 1, "api_id": "12345678", "api_hash": "0123456789abcdef0123456789abcdef" }
}
```

## Пример успешного ответа

Успех подтверждает сохранение настроек. Секреты и session string не должны раскрываться в ответе или логах.

## Типичные ошибки

- Переданы неизвестные или пропущенные обязательные параметры.
- `enabled` не равен `0` или `1`.
- `token_id` не принадлежит проекту.
- API ID/Hash или session string имеют неверный формат.
- Агент ожидает применения без запуска или перезапуска бота.

## Ограничения и безопасность

Тул может изменять live-БД, проект или состояние бота. Выполняй его только в рамках явной просьбы пользователя и проверь результат после операции.
- Не перезапускай бота автоматически; перезапуск допустим только по явной просьбе пользователя.
- После операции перечитай состояние и вызови подходящую проверку или логи.
- Если тул требует `confirm`, передавай его только после подтверждения пользователя.

## Связанные инструменты
