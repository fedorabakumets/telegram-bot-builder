# `db_userbot_send_code`

## Назначение

Шаг 1 авторизации Telethon: отправляет код на телефон. Без `api_hash` использует сохранённый Hash. Код не возвращается MCP — его вводит пользователь из Telegram.

## Когда использовать

Перед вызовом сохрани настройки через `db_set_userbot_settings` или передай Hash в этом запросе. Используй тот же `project_id` и `token_id` в следующих шагах.

## Параметры

- `project_id` — number; обязательный.
- `token_id` — number; обязательный.
- `api_id` — непустая string; обязательный API ID.
- `phone` — непустая string; обязательный номер с кодом страны.
- `api_hash` — string; необязательный сохранённый или новый API Hash.

Точные типы и обязательность берутся из схемы MCP-регистрации. Перед вызовом проверь описание инструмента в MCP-клиенте; не придумывай отсутствующие поля.

## Пример вызова

```json
{
  "tool": "db_userbot_send_code",
  "arguments": { "project_id": 42, "token_id": 7, "api_id": "12345678", "phone": "+79991234567" }
}
```

## Пример успешного ответа

Успех означает, что код отправлен; сохрани телефон и сразу попроси пользователя передать код. Следующий шаг — `db_userbot_sign_in`.

## Типичные ошибки

- Переданы неизвестные или пропущенные обязательные параметры.
- Не сохранён API Hash и он не передан.
- Номер не совпадает с текущей сессией или имеет неверный формат.
- Повторная отправка заблокирована Telegram по лимиту.

## Ограничения и безопасность

Тул только читает данные или выполняет проверку; он не должен изменять проект, БД или состояние бота.
- Не трактуй отсутствие ошибки транспорта как подтверждение бизнес-корректности результата.
- Для дальнейшего изменения используй отдельный mutating-тул после проверки данных.

## Связанные инструменты

- `get_tool_docs` — получить карточку этого и связанных тулов.
- `search_tool_docs` — найти подходящие инструменты.
- `get_workflow_docs` — получить рекомендуемую последовательность действий.

## Рекомендуемый следующий шаг

Не логируй Hash или код. После получения кода вызови `db_userbot_sign_in` с теми же ID и телефоном.
