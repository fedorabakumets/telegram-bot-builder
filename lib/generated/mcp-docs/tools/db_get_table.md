# `db_get_table`

## Назначение

Возвращает пользовательскую таблицу проекта, её столбцы с числовыми ID и сводку заполненности. Read-only.

## Когда использовать

Вызывай перед записью строк или настройкой `bot_table`-ноды: сначала получи `table_id` и реальные ID столбцов. Системные таблицы пользователей и сообщений сюда не входят.

## Параметры

- `project_id` — number; обязательный параметр.
- `table_id` — number; обязательный параметр.

Точные типы и обязательность берутся из схемы MCP-регистрации. Перед вызовом проверь описание инструмента в MCP-клиенте; не придумывай отсутствующие поля.

## Пример вызова

```json
{
  "tool": "db_get_table",
  "arguments": { "project_id": 42, "table_id": 12 }
}
```

## Пример успешного ответа

Успешный ответ содержит ID/имя таблицы, список столбцов и статистику строк. Для самих строк используй `db_list_table_rows`, а не этот тул.

## Типичные ошибки

- Переданы неизвестные или пропущенные обязательные параметры.
- `table_id` не принадлежит `project_id`.
- Агент передал имя столбца вместо его числового ID.
- Таблица удалена или недоступна текущему MCP-токену.

## Ограничения и безопасность

Тул только читает данные или выполняет проверку; он не должен изменять проект, БД или состояние бота.
- Не трактуй отсутствие ошибки транспорта как подтверждение бизнес-корректности результата.
- Для дальнейшего изменения используй отдельный mutating-тул после проверки данных.

## Связанные инструменты

- `get_tool_docs` — получить карточку этого и связанных тулов.
- `search_tool_docs` — найти подходящие инструменты.
- `get_workflow_docs` — получить рекомендуемую последовательность действий.

## Рекомендуемый следующий шаг

Сохрани реальные ID столбцов и используй их в `db_add_table_rows`, `db_patch_table_row` или настройке `bot_table`.
