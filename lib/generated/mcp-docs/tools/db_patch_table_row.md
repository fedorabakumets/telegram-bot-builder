# `db_patch_table_row`

## Назначение

Изменяет только переданные ячейки строки; остальные значения сохраняются. Пустая строка — реальное значение, а не команда удалить поле.

## Когда использовать

Используй для точечного обновления после `db_find_table_rows` или `db_get_table_row`. Операция изменяет БД, но отдельный `confirm` не требуется.

## Параметры

- `project_id` — number; обязательный параметр.
- `table_id` — number; обязательный параметр.
- `row_id` — number; обязательный ID строки.
- `data` — object; обязательная карта `"column_id": "новое значение"`.

Точные типы и обязательность берутся из схемы MCP-регистрации. Перед вызовом проверь описание инструмента в MCP-клиенте; не придумывай отсутствующие поля.

## Пример вызова

```json
{
  "tool": "db_patch_table_row",
  "arguments": { "project_id": 42, "table_id": 12, "row_id": 88, "data": { "102": "Оплачен" } }
}
```

## Пример успешного ответа

Ответ подтверждает обновление строки. После операции перечитай строку, если результат используется в следующей операции бота.

## Типичные ошибки

- `row_id` не принадлежит таблице.
- Ключ `data` не является ID существующего столбца строкой.
- Значение не строка или запись относится к другому проекту.

## Ограничения и безопасность

Тул может изменять live-БД, проект или состояние бота. Выполняй его только в рамках явной просьбы пользователя и проверь результат после операции.
- Не перезапускай бота автоматически; перезапуск допустим только по явной просьбе пользователя.
- После операции перечитай состояние и вызови подходящую проверку или логи.
- Если тул требует `confirm`, передавай его только после подтверждения пользователя.
