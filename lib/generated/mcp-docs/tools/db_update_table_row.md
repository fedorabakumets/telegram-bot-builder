# `db_update_table_row`

## Назначение

Полностью заменяет карту ячеек строки. Передавай все значения, которые должны остаться: отсутствующие ячейки не считаются сохранёнными.

## Когда использовать

Используй, когда нужно заменить всю строку. Для изменения одной-двух ячеек безопаснее `db_patch_table_row`.

## Параметры

- `project_id` — number; обязательный параметр.
- `table_id` — number; обязательный параметр.
- `row_id` — number; обязательный ID строки.
- `data` — object; обязательная полная карта `"column_id": "значение"`.

Точные типы и обязательность берутся из схемы MCP-регистрации. Перед вызовом проверь описание инструмента в MCP-клиенте; не придумывай отсутствующие поля.

## Пример вызова

```json
{
  "tool": "db_update_table_row",
  "arguments": { "project_id": 42, "table_id": 12, "row_id": 88, "data": { "101": "Анна", "102": "Оплачен" } }
}
```

## Пример успешного ответа

Ответ подтверждает полную замену строки. Перечитай строку, чтобы убедиться, что нужные ячейки не потеряны.

## Типичные ошибки

- `data` не содержит обязательного полного набора или имеет неизвестный ID столбца.
- `row_id` не принадлежит таблице.
- Значения переданы не строками.

## Ограничения и безопасность

Тул только читает данные или выполняет проверку; он не должен изменять проект, БД или состояние бота.
- Не трактуй отсутствие ошибки транспорта как подтверждение бизнес-корректности результата.
- Для дальнейшего изменения используй отдельный mutating-тул после проверки данных.

## Связанные инструменты

## Рекомендуемый следующий шаг

Проверь строку через `db_get_table_row`; для частичной правки используй `db_patch_table_row`.
