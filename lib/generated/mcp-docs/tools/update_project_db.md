# `update_project_db`

Записать сценарий проекта и получить квитанцию сохранения. Передайте expected_revision из чтения проекта для защиты от перезаписи конкурентных правок. Без неё сохраняется совместимый безусловный режим. Рассылка обновления холста не подтверждает применение интерфейсом.

Раздел: scenario. Транспорт: http, stdio.

## Параметры

```json
{
  "type": "object",
  "properties": {
    "project_id": {
      "type": "number",
      "description": "Числовой ID проекта из URL редактора"
    },
    "project_json": {
      "anyOf": [
        {
          "type": "string"
        },
        {
          "type": "object",
          "additionalProperties": {}
        }
      ],
      "description": "project.json"
    },
    "expected_revision": {
      "type": "integer",
      "minimum": 0,
      "description": "Ревизия прочитанного проекта; при конфликте сохранение отклоняется."
    },
    "commit_message": {
      "type": "string",
      "description": "Заметка к версии (ручной чекпоинт)"
    },
    "skip_validation": {
      "type": "boolean",
      "description": "Пропустить валидацию перед записью"
    }
  },
  "required": [
    "project_id",
    "project_json"
  ],
  "additionalProperties": false,
  "$schema": "http://json-schema.org/draft-07/schema#"
}
```

## Эффект

## Пример вызова

```json
{
  "action_id": "update_project_db",
  "args": {
    "project_id": 1,
    "project_json": "1"
  }
}
```

Структурный пример проверен Zod; ID и данные замените реальными.

## Ответ и ошибки

Прежний text content сохранён. Метаданные `_meta.botcraft` различают prepared/read/saved/pending/partial/unknown/error/unverified. Только `persistence.confirmed=true` подтверждает сохранение. Неизвестный исход требует чтения состояния до повтора; live-доставка и применение ботом проверяются отдельно.

## Ограничения и безопасность

Изучите describe_actions, проверьте реальные ID и права проекта. Для разрушительных и внешних действий требуется явное намерение пользователя. Для повторов сохраняйте requestId, если он объявлен. Отсутствие ошибки транспорта не доказывает сохранение.
