# `db_duplicate_project`

Дублировать проект целиком (полная копия сценария со всеми листами и связями) в БД живого приложения. Bot token НЕ копируется — копия создаётся без токена. Опционально имя копии (по умолчанию «{имя источника} (копия)»). Возвращает id новой копии.

Раздел: projects. Транспорт: http, stdio.

## Параметры

```json
{
  "type": "object",
  "properties": {
    "source_project_id": {
      "type": "number",
      "description": "ID проекта-источника"
    },
    "name": {
      "type": "string",
      "description": "Имя копии (по умолчанию «{имя} (копия)»)"
    },
    "request_id": {
      "type": "string",
      "format": "uuid",
      "description": "UUID одного намерения; сохраните для безопасного повтора"
    }
  },
  "required": [
    "source_project_id"
  ],
  "additionalProperties": false,
  "$schema": "http://json-schema.org/draft-07/schema#"
}
```

## Эффект

```json
{
  "section": "projects",
  "effect": "write",
  "completionMode": "immediate",
  "destructive": false,
  "runtimeApply": "not_applicable"
}
```

## Пример вызова

```json
{
  "action_id": "db_duplicate_project",
  "args": {
    "source_project_id": 1
  }
}
```

Структурный пример проверен Zod; ID и данные замените реальными.

## Ответ и ошибки

Прежний text content сохранён. Метаданные `_meta.botcraft` различают prepared/read/saved/pending/partial/unknown/error/unverified. Только `persistence.confirmed=true` подтверждает сохранение. Неизвестный исход требует чтения состояния до повтора; live-доставка и применение ботом проверяются отдельно.

## Ограничения и безопасность

Изучите describe_actions, проверьте реальные ID и права проекта. Для разрушительных и внешних действий требуется явное намерение пользователя. Для повторов сохраняйте requestId, если он объявлен. Отсутствие ошибки транспорта не доказывает сохранение.
