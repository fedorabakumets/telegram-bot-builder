# Workflow: калькулятор

## Цель

Принять два числа, получить операцию кнопкой, вычислить результат и показать его.

## Цепочка

```text
/start → вопрос → input(first_number) → вопрос → input(second_number)
→ keyboard(+ − × ÷) → input(operation, callback)
→ code(answer) → message({answer})
```

## Правила

- Для чисел используй `validationType: "number"` и `retryMessage`.
- Для операции сохраняй callback в переменную `operation`.
- В code-ноду передавай значения через пользовательские переменные.
- Обработай деление на ноль.
- `/start` должен начинать новый сценарий и не использовать старые значения без проверки.
- После изменения вызови `validate_bot_project`; перезапуск бота делай только по явной просьбе пользователя.
