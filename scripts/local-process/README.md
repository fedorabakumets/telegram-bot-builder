# Сквозные локальные проверки process

Запуск из корня проекта:

```powershell
.venv/Scripts/python.exe scripts/local-process/test_integration.py -v
```

Нужны зависимости проекта и Redis на `127.0.0.1:6379`. Другой адрес задаётся через `DEMAND_TEST_REDIS_URL`.

Проверки запускают настоящий дочерний Python с aiogram, настоящий Redis и имитацию Telegram API на loopback. Токены случайные; настоящие боты и внешний Telegram не используются. Каждый тест удаляет только свои случайные ключи Redis.

Проверяется завершение PID после простоя, повторное пробуждение с сохранённым состоянием, отсутствие импорта aiogram у приёмника, ограничение параллельных обработчиков, сохранность очереди при аварийном выходе и отказе получателя.

Это проверка жизненного цикла и доставки. Она не измеряет память настоящего сценария или задержку внешнего Telegram.
